# Pokédex

Aplicación web en JavaScript puro que consume la [PokeAPI](https://pokeapi.co/) (REST).

## Qué hace
- Búsqueda de Pokémon por nombre o número.
- Filtros por tipo.
- Carga progresiva del listado ("cargar más").
- Ficha de cada Pokémon con barras de estadísticas.
- Diseño responsive (desktop y celular).

## Stack
HTML5, CSS3 (Flexbox y Grid) y JavaScript (ES6+, `fetch`). Sin frameworks ni dependencias.

## Cómo correrlo
Abrir `index.html` en el navegador, o servir la carpeta con cualquier servidor estático.
